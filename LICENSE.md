Anima‑Vectorium Dual License Structure

Anima‑Vectorium contains two distinct code families with different licenses.  
This structure ensures:

- geometric components remain free and open  
- expressive components derived from Stell’s work remain non‑commercial  
- no license contamination occurs  
- dual‑use and human‑rights restrictions are enforced  

---

1. Geometric Components — Licensed under GVL‑1.0
Covered by LICENSE-GEOMETRY.txt.

This includes:

`
vectorium/core/
vectorium/geometry/
vectorium/diagnostics/
vectorium/safety/
vectorium/utils/
`

These components are:

- free  
- open  
- modifiable  
- redistributable  
- dual‑use restricted  
- rights‑aligned  
- commercially licensable  

---

2. Anima‑Derived Components — Licensed under Stell’s Non‑Commercial License
Covered by LICENSE-ANIMA.txt.

This includes:

`
animahologramv3.1/
animaclassicarchive/
any expressive operators derived from Stell’s work
`

These components:

- may be used  
- may be modified  
- may be redistributed  
- may NOT be used commercially  
- must retain Stell’s license  
- must retain attribution  

---

3. Separation of Concerns
To avoid license contamination:

- geometric code never depends on Anima‑derived code  
- Anima‑derived code never incorporates geometric code  
- derivative works must preserve both licenses  
- contributors must respect both license families  

---

4. Summary
- Use GVL‑1.0 for all geometric, holonomy, curvature, drift, stability, multimodal, and rights‑aligned components.  
- Use Stell’s Non‑Commercial License for expressive components derived from Anima Classic or Anima‑Hologram.  
- Follow dual‑use restrictions and non‑weaponization clauses.
